Mohit Bagora portfolio - static site, no build step.

Files:
  index.html                      the whole site (HTML + CSS + JS)
  assets/photo.jpg                hero portrait
  assets/Mohit_Bagora_Resume.pdf  resume download

Run locally:  python3 -m http.server   then open http://localhost:8000
Host free:    drag this folder onto Netlify Drop, or push to GitHub and enable GitHub Pages.

Dependencies loaded from CDN: Three.js r128 (cdnjs), Google Fonts.
To add your LinkedIn link, edit the 'network' contact item near the bottom of index.html.
